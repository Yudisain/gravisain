== Description ==

Gravisain is a premium hybrid WordPress theme built as a flexible design system for modern, high-performance websites. Engineered for exceptional speed, with modular Header & Footer Builders, deep WooCommerce integration, full Gutenberg block support, and powerful global design controls.

== Installation ==

1. In your WordPress admin dashboard, navigate to Appearance > Themes and click the "Add New" button.
2. Click "Upload Theme" at the top of the page.
3. Choose the `gravisain.zip` file and click "Install Now".
4. Once installed, click "Activate".
5. Run `composer install` in the theme directory if you are setting up a development copy. (The distribution zip already includes vendor dependencies).

== Frequently Asked Questions ==

= Does this theme support the WordPress Customizer? =
Yes, Gravisain is a hybrid theme. All global layout options, colors, typography, Header layouts, and Footer widget areas are configured 100% via the WordPress Customizer.

= Does Gravisain work with WooCommerce? =
Yes, Gravisain has built-in deep WooCommerce integration, including modular grid product lists and customizable distraction-free checkout options.
